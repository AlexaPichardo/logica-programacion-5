#  Ejercicio de Lógica de Programación 5: Diccionario Español-Inglés en Java

Este repositorio contiene la solución a un ejercicio práctico desarrollado en **Java**, 
cuyo objetivo es implementar estructuras de datos y lógica de control para crear un juego interactivo de traducción.

---

##  Descripción del Problema
El programa realiza las siguientes acciones clave:
1. **Estructura de Datos (`HashMap`):** Almacena un mini diccionario con al menos 20 parejas
   de palabras (Español-Inglés) enfocadas en naturaleza, animales y elementos cotidianos.
2. **Selección Aleatoria:** Extrae y selecciona automáticamente 5 palabras al azar de la lista
   utilizando la clase `Random` (o colecciones de Java) para asegurar que no se repitan en la misma ejecución.
3. **Interacción por Consola (`Scanner`):** Pide al usuario que teclee la traducción al inglés
   de cada palabra seleccionada, aplicando validaciones para limpiar espacios y evitar problemas
   con mayúsculas/minúsculas (`trim().toLowerCase()`).
4. **Reporte de Resultados:** Al finalizar las 5 preguntas, muestra un resumen detallado con el
   conteo total de respuestas correctas e incorrectas.
